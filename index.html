ELF Studio

把本地 ELF 文件拖进窗口（或点击左上角按钮选择文件），即可在浏览器内即时完成解析： 多色块 Hex 视图、结构表格、字节级探针、枚举字典与 RISC-V 反汇编全部联动。

多色块 Hex 视图按 ELF 物理结构逐字节着色，一眼看清头部、代码、数据、符号表、字符串表的分界线。
视窗联动在右侧表格、符号表或反汇编里点击任意条目，左侧 Hex 会自动滚动并高亮对应物理字节。
字节级探针悬停任意字节即可看到文件偏移、虚拟地址、所属字段名与功能说明。
枚举全量字典e_type、e_machine、sh_type、p_type 等枚举列出全部规范取值、定义与原理，并标记本文件实际取值。
RISC-V 反汇编支持 RV32/RV64 I/M/A/F/D + 压缩指令 C 与常用 Zba/Zbb/Zbs 扩展，并自动标注跳转目标符号。
符号表导航解析 .symtab / .dynsym，函数符号一键跳转反汇编并映射回 Hex 物理位置。
快捷键：⌘O / Ctrl+O 打开文件　·　在 Hex 视图中用方向键、PageUp/PageDown 逐字节浏览
Hex 视图 按结构着色 · 单击选中 · 拖动框选 · 方向键移动
方向键逐字节 · 上下键整行 · PageUp/Down 翻页 · [ ] 逐字段 · Esc 取消固定
